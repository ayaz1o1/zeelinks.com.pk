How to Test CCTV Ethernet Cabling Before Handover

A practical IP camera cabling test procedure covering wiremap, link speed, PoE and real-world camera operation.

Visual inspection

Inspect the cable route, connectors, patch panels, bend radius and termination quality. Look for crushed cable, poor crimping and unsuitable routing.

Wiremap is only the first test

A basic tester can detect opens, shorts and wiring-order errors. Passing a wiremap test does not prove that the cable will reliably carry the required Ethernet speed.

Test the negotiated link

Connect the actual switch and camera and verify the expected link speed. A link that negotiates below the expected rate deserves investigation.

Test PoE under load

Confirm the camera receives power and remains stable. Check the switch's PoE statistics, especially during night operation when IR may increase demand.

Test the complete path

Verify live video, recording, playback and remote viewing through the actual network path. This catches problems that a cable tester alone cannot.

Document everything

Label cable IDs, camera names, switch ports, test results and any remedial work so future troubleshooting starts with accurate information.
