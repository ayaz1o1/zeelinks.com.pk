NVR Multi-Camera Live View: Main Stream vs Substream

Understand how main streams and substreams affect recording, live viewing and NVR decoding.

Main stream

Usually used for higher-quality recording and consumes more bandwidth and decoding resources.

Substream

A lower-resolution stream can reduce decoding load for multi-camera live view while the main stream remains available for recording.

Decoding limits

An NVR may display many low-resolution tiles but support fewer simultaneous high-resolution views.

Commissioning

Test expected live-view tiles, full-screen switching, playback and remote viewing before handover.
