# Phase 4A — IPv4 Networking Tool Upgrade

Upgraded the existing IP Calculator into an IPv4 Subnet & IP Address Calculator.

Includes subnet mask, CIDR, network/broadcast, host range, wildcard mask, address classification, private RFC1918 ranges, public/global-unicast explanation, 0/8, 100.64/10, 127/8, 169.254/16, documentation ranges, benchmark range, multicast and reserved ranges, plus a CIDR reference table.

Public IPv4 is explained as a concept rather than pretending it is one contiguous range.
