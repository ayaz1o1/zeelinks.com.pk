# Phase 4B-2 — IP Range & Host Calculator

Added after the VLSM/Subnet Planner.

Features:
- IPv4 host address input
- CIDR and subnet-mask input
- Automatic containing-network calculation
- Network address
- First/last usable host
- Broadcast
- Total and usable addresses
- Wildcard mask
- Private/public/special-use classification
- Practical subnet-boundary table
- CCTV/networking examples
- Links to the IPv4 calculator and VLSM planner
