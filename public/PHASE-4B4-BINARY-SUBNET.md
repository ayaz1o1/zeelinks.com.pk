# Phase 4B-4 — IPv4 ↔ Binary Converter & Subnet Bit Explorer

Added after the IPv4 subnet, range, VLSM and wildcard tools.

Features:
- IPv4 decimal to binary conversion
- Subnet mask to binary
- Network address and binary
- Wildcard mask
- CIDR prefix selection
- Network-bit vs host-bit visualization
- 32-bit / four-octet representation
- Address and usable-host counts
- CIDR bit-pattern reference
- Links to all related networking tools

This is intentionally educational as well as functional, helping users understand why subnet masks and CIDR boundaries work rather than only giving a calculated answer.
