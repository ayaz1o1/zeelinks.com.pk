# Phase 4B — VLSM / Subnet Planner

Built on the Phase 4A IPv4 networking tool.

Features:
- Parent IPv4 network/CIDR input
- Multiple named subnet requirements
- Host-count input
- Largest-to-smallest VLSM allocation
- Automatic CIDR selection
- Subnet mask
- Network address
- First/last usable host
- Broadcast address
- Remaining address-space calculation
- Traditional host calculation
- Optional /31 point-to-point-aware mode
- CCTV / office / Wi-Fi / management example
- Links back to the IPv4 calculator and related tools

This tool is designed to become the foundation for future VLAN and network-capacity planning tools.
