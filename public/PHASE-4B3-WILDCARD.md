# Phase 4B-3 — Wildcard Mask Calculator

Added after the IPv4 Subnet, IP Range and VLSM tools.

Features:
- Subnet mask to wildcard conversion
- CIDR to wildcard conversion
- Network/base address input
- Binary subnet and wildcard display
- Cisco-style `network wildcard` pattern
- Wildcard matching test
- /0 through /32 reference
- Common /24 through /30 wildcard examples
- Explanation of 0 = must match and 1 = ignore
- Cisco ACL and OSPF context
- Links to related Zee Links networking tools
