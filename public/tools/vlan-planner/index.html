CCTV VLAN Design Notes

  • Put cameras into a dedicated CCTV VLAN when the network design and equipment support it.
  • Restrict camera-to-user and camera-to-internet traffic according to the actual security requirement.
  • Keep NVR management access separate from general user access where practical.
  • Use the VLSM Planner first when different VLANs need different subnet sizes.
  • Document the gateway, DHCP scope, static camera range and management addresses before deployment.
