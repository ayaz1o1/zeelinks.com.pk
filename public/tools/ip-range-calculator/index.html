IP Range & Host Calculator

Enter an IPv4 address and CIDR or subnet mask to see the complete subnet range, usable hosts, network and broadcast addresses, wildcard mask and address classification.

The input address may be a host address. Unlike the VLSM planner, this tool automatically finds the containing network.

What the IP Range Means

Network AddressIdentifies the subnet

Normally the first address in a traditional IPv4 subnet.

First Usable HostNetwork + 1

Normally the first assignable host address.

Last Usable HostBroadcast − 1

Normally the last assignable host address.

Broadcast AddressLast address

Used to reach all hosts in a traditional IPv4 subnet.
