How VLSM Works

VLSM — Variable Length Subnet Masking lets you divide one address block into subnets of different sizes. Instead of giving every department the same number of addresses, each group receives a subnet sized for its actual requirement.

Example: If CCTV needs 60 hosts, office PCs need 30, Wi-Fi needs 20 and management needs 10, using VLSM avoids wasting a full /24 for every group.

Planning method

  1. Choose the parent network.
  2. List required hosts for each segment.
  3. Sort requirements from largest to smallest.
  4. Allocate the smallest suitable subnet for each requirement.
  5. Verify that every allocated subnet stays inside the parent network and does not overlap.

Important practical points

  • Traditional IPv4 LAN subnets reserve the network and broadcast addresses, so usable hosts are normally total addresses minus two.
  • A /31 can be used for suitable point-to-point links under RFC 3021 and does not provide the usual network/broadcast host model.
  • A /32 represents a single IPv4 address and is commonly used for host routes rather than a normal LAN subnet.
  • VLSM is an addressing technique; it does not itself create VLANs, routing or DHCP scopes.
