Wildcard Matching Test

Enter a base/network address and a wildcard mask. In Cisco-style wildcard logic, 0 = must match and 1 = ignore this bit.

Example: 192.168.10.0 0.0.0.255 matches addresses from 192.168.10.0 through 192.168.10.255.

Why Cisco Uses Wildcard Masks

A subnet mask describes which bits belong to the network. A wildcard mask is its inverse: 0 bits are significant and must match; 1 bits are ignored.

Example:
Network: 192.168.10.0
Subnet mask: 255.255.255.0
Wildcard: 0.0.0.255

This means the first three octets must match, while the last octet can vary from 0 to 255.

Common Cisco contexts

  • Standard and extended IPv4 ACL entries.
  • OSPF network statements on Cisco IOS.
  • Other Cisco features that use wildcard-style matching.

Important: wildcard masks are not the same thing as subnet masks. A subnet mask's 1 bits identify the network portion; a wildcard mask's 0 bits identify the bits that must match.
