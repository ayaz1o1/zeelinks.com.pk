# Zee Links CCTV Disk Calculator

Two calculation modes:
- Recording Space: cameras + bitrate/resolution + recording hours + days -> storage.
- Recording Time: cameras + bitrate/resolution + disk capacity + recording hours -> retention.

Resolution mode uses practical baseline bitrate estimates. Bitrate mode is recommended for exact NVR planning because actual bitrate depends on the camera/NVR configuration, scene complexity, VBR/CBR, audio and other settings.
