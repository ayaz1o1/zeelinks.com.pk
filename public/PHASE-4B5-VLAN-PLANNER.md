# Phase 4B-5 — VLAN Planner

Built on the Phase 4B networking-tool chain.

Features:
- VLAN ID validation (1–4094)
- VLAN name and purpose
- IPv4 subnet/CIDR
- Automatic gateway suggestion
- DHCP range suggestion
- Usable-host capacity
- Duplicate VLAN ID detection
- IPv4 subnet overlap detection
- Site/project and routing-device documentation
- CCTV, office, Wi-Fi, guest and management examples
- Practical Layer-2 / Layer-3 segmentation guidance
- Links to IPv4, VLSM, range, wildcard and binary tools
